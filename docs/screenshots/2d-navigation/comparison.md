# 2D navigation visual comparison

The same demo project, 1440 × 900 browser viewport, and 2D workspace are shown in [before-plan.png](before-plan.png) and [after-plan.png](after-plan.png). The paired 3D captures, [before-exterior.png](before-exterior.png) and [after-exterior.png](after-exterior.png), use the same project, front camera, daylight preset, and quality settings. The plan UI change does not claim an exterior visual improvement.

The baseline plan extends beyond the visible workspace and exposes editing actions immediately. The new fit view contains the whole plot, displays the current zoom level, and keeps the compass and scale bar on the screen. [zoomed-plan.png](zoomed-plan.png) shows cursor zoom; [touch-gesture-plan.png](touch-gesture-plan.png) follows a two-point touch gesture; [editor-plan.png](editor-plan.png) shows the explicit Editing state and B1 tools. At small scale, minor dimensions disappear so the room names and major information stay legible. Crisp vector strokes remain visible as the view changes.

The browser script checks the wheel cursor position in plan feet, Fit and 100%, the fixed compass, a two-finger gesture, view-only room drag protection, and Editor persistence after reload. It does not establish readability on every physical screen or test a physical iPad; the touch proof uses Chromium touch input. Dense labels can still compete at intermediate zooms, and the plan is a diagram rather than the furnished cutaway of [plan-01-cutaway.png](../../references/plan-01-cutaway.png) or [plan-02-cutaway-4bhk.png](../../references/plan-02-cutaway-4bhk.png).

The primary exterior references [ext-01-contemporary-slats.png](../../references/ext-01-contemporary-slats.png) and [ext-02-jaali-stone.png](../../references/ext-02-jaali-stone.png) remain the style targets for the demo facade. This navigation change leaves the front silhouette effectively the same and does not close the existing material, planting, and lighting gap to those images. No Pixabay element reference was used for this UI change.
